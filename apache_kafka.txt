Why do we need Kafka??


Components in Kafka:


1) Pub/Sub Model


Publisher: publishes the message


Message Broker: stores the message


Subscriber: listens to the message



2) Producer: publishes, creates and posts the message on broker/Kafka Server

3) Kafka Broker: just a server. it is an intermediate entity that helps
in message exchanges between a producer and consumer.

4) Cluster: group of server/ computer working on a single purpose.
one or more kafka broker insde a cluster.

5) Topic:

Publisher can publish any sort of messages (like UPI payment,
Card payment, flight booking etc etc)

Now Consumer asks give me all  payment related messages

now broker says i have lot of payment related messages which one 
do you want?? Now consumer is stuck

that is where topic came into picture to catergorize different
form of messages.

you can create multiple topic for different types of messages.

e.g Payment Topic, Booking Topic, Insurance Topic

Consumer needs to subscribe to a particular topic and get all the messages

they act as tables inside kafka eco system

It specifies the category of the message or the classification of the
message. Listener can then just respond to the messages that belong
to the topics they are listening on.

6) Partitions: 

producer is producing billions and trillions of message to a topic.

You can break the kafka topic into different sub topics and can 
distribute it on a machine. these are called partitions.

7) Offset: 

number assigned to each and every message.

It keeps track of which all message has been read by consumer.


8) Consumer Groups: multiple consumer instances for multiple partitions

9) Zookeeper: It keeps track of kafka cluster.

Method 2) For mentioning Serialization and Deserialization


you can do it while doing configuration


inside the @Configuration class where you defined topic bean


@Bean
public Map<String,Object> producerConfig(){

Map<String, Object> props = new HashMap<>();


props.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, "localhost:9092")
props.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, StringSerializer.class)
props.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, JsonSerializer.class)



@Bean
public ProducerFactory<String, Object> producerFactory(){

return new DefaultKafkaProducerFactory<>(producerConfig());

}


@Bean
public KafkaTemplate<String, Object> kafkaTemplate()[

return new KafkaTemplate<>(producerFactory());
}
