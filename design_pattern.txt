class Computer{

private String computerName;
private int ramSize;

private Computer(ComputerBuilder cb){

this.computerName = cb.computerName;
this.ramSize = cd.ramSize;

}

public static class ComputerBuilder{

private String computerName;
private int ramSize;

public ComputerBuilder setComputerName(String name){
this.computerName=name;
return this;
}

public ComputerBuilder setRamSize(int size){
this.ramSize=size;
return this;
}

public Computer build(){
    return new Computer(this);
}
}

** Problem: 

1) This is going to bloat our class and we have to keep adding multiple if else to cater to the statement

2) This single class will eventually become thousands of lines long and impossible to read.


Solution:


create an interface and create multiple classes for different implementation

interface PaymentMode
{
void processPayment(Double amount);
}

class CreditCard implements PaymentMode
{
void processPayment(Double amount)
{
  // processed using Credit card
}
}

class DebitCard implements PaymentMode
{
void processPayment(Double amount)
{
  // processed using Debit card
}
}


// problem solved
public class CheckoutManager{
