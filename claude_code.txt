#5) Context Window Management

- Context Window - is the amount of information(in tokens)
that a model like cc can see and remember at one time while generating
a response


- context - all the information available to understand something
correctly

context window - the max amount of context the model can hold at once

#6) Claude.md file

- LLM's dont have memory

- cc cannot remember things from prev sessions

- need to repeat instructions across sessions

- repeating instructions is cumbersome & error prone


claude.md - project level instruction file used by cc to guide how it behaves
while working on your codebase


ways to make this file 

1) manually

2) using /init - cc spins up an internal agent and it scans your project.
reads the directory structure.. infers tech stack and naming convention and then
it creates the claude.md file



what should be in claude.md file

1) Project Context: description of file

2) Explain your code structure and some business logic and things you use

3) preferred libraries - constraints tools/frameworks to be used

4) commands - list commands for running, tsting and maintaining the project

5) critical rules: highlight critical warnings, edge cases, and things to avoid

e.g do not make changes in database file
